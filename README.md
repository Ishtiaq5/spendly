# Spendly — Premium Expense & Budget Tracker

A single-page, dependency-free expense tracker with a dark premium aesthetic.

## Features

- Budget ring that fills as you spend (SVG stroke animation, gradient stroke)
- Live stats: spent, remaining, daily average, entry count
- Add / delete expenses with category colours
- Category breakdown with animated bars
- Everything persists in `localStorage` — no backend, nothing leaves the browser
- Responsive from 360px up, semantic HTML + ARIA labels

## Stack

Vanilla HTML + CSS + JS. No frameworks, no CDN, no build step.

## Files

```
index.html
css/styles.css
js/main.js
```

## Run

Open `index.html` directly in a browser, or serve the folder with any static server.
